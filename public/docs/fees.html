费用花在哪里，付给谁？

核对日期：2026-09-28。以下是上游当日价格说明，不是 TapeNow 的套餐报价，也不是永久价格承诺。操作前以所选链的最新报价、钱包确认和交易回执为准。

Base 的 0.0012 ETH／30 天激活费，不是 TapeNow 收取的平台服务费。钱包把这笔钱直接支付给 TapeKit 使用的上游 DomainBinding（域名绑定）合约。TapeNow 不代收、不对这笔协议激活费加价；gas 另计。

先分清几笔钱

  • 交易 gas：支付给所在区块链网络，用于执行交易。BSC 使用 BNB，X Layer 使用 OKB，Base 使用 ETH；Base 还包含 L1 数据等网络费用。失败的交易也可能消耗 gas。
  • 上游协议费用：芯片流片、容器开通、网站地址激活等是不同操作，各自按上游合约定价。激活费发送给上游域名绑定合约，不属于 TapeNow 平台收费，也不包含前两项费用。
  • 云服务和域名：你自己连接的 Cloudflare、Supabase、GitHub 等按各自套餐计费；购买及续费普通域名的钱付给域名注册商。TapeNow 提供的测试资源另有用量限制，不能理解为供应商资源无限免费。
  • TapeNow 平台费：不要把钱包里的上述 gas 和协议转账记成 TapeNow 服务费。本文没有新增 TapeNow 收费项目，也不替代未来平台套餐的独立说明。

用 TapeNow Gateway，为什么还会看到激活费？

Gateway 为已有链上网站提供普通 HTTPS 入口，但当前版本仍检查上游容器和地址是否有效。使用 Gateway 不会免除底层协议的激活要求。这不等于 HashPort 已经支持 X Layer 或 Base 托管：TapeNow Gateway 是独立的访问服务。

访客打开网站不需要钱包，也不用为每次访问付 gas。发布者的新建、写入、更新和激活交易可能产生费用。Gateway 的持有人消息签名只证明归属，本身不是付款交易。

30 天到了，会发生什么？

到期的是协议的访问资格，不是你的普通域名被收回，也不表示历史链上字节消失。原生入口及 TapeNow Gateway 可能停止提供访问；延长激活、重新核验后才能恢复。TapeNow 当前不会自动扣款续期。BSC 即使免激活服务费，也仍需保持有效的链上记录。

What costs money, and who receives it?

Checked on 28 September 2026. These are upstream prices observed on that date, not a TapeNow pricing plan or a promise of permanent rates. Review the selected chain's current quote, wallet confirmation and transaction receipt before paying.

The Base activation fee of 0.0012 ETH per 30 days is not a TapeNow platform fee. Your wallet pays the upstream DomainBinding contract used by TapeKit directly. TapeNow neither collects nor marks up this protocol activation fee. Network gas is separate.

Separate the costs

  • Network gas: paid to the blockchain for transaction execution. BSC uses BNB, X Layer uses OKB and Base uses ETH. Base also includes L1 data and other network fees. Failed transactions may still consume gas.
  • Upstream protocol fees: chip creation, container opening and site-address activation are separate operations with their own contract prices. Activation value goes to the upstream binding contract, not TapeNow, and does not include chip or container costs.
  • Cloud services and domains: your connected Cloudflare, Supabase and GitHub accounts follow their own plans. Ordinary domain registration and renewal are paid to your registrar. TapeNow test resources also have usage limits; provider resources are not unlimited or universally free.
  • TapeNow platform fees: do not classify the network and protocol transfers above as TapeNow service charges. This document introduces no new TapeNow charge and does not replace a separate explanation of any future platform plan.

Why does TapeNow Gateway still require activation?

Gateway provides an ordinary HTTPS entry for an existing on-chain website. The current release still checks upstream container and address validity, so Gateway does not waive protocol activation requirements. This does not mean HashPort offers X Layer or Base hosting: TapeNow Gateway is a separate access service.

Visitors need neither a wallet nor gas for each visit. Publishers may pay for creation, writes, updates and activation. Gateway's ownership message signature proves control and is not itself a payment transaction.

What happens after 30 days?

Protocol access eligibility expires; your ordinary domain is not taken away and historical on-chain bytes do not disappear. The native entry and TapeNow Gateway may stop serving the site until activation is extended and verified again. TapeNow does not automatically charge for renewal. Even on BSC, where the activation service fee is zero, an active on-chain record is still required.
