让 Agent 和你一起发布

登录 TapeNow 后，支持原生 WebMCP 的浏览器会显示“Agent 工具已就绪”。Agent 可以查询项目和版本、生成示例、准备发布或恢复，并继续你已经批准的操作。

限量公测中。支持 Chrome 149 及以上版本：通过 Chrome 的 WebMCP origin trial 启用，不需要打开测试 flag（试验覆盖到 Chrome 162，最晚 2027 年 3 月 29 日结束）。还需要一个能够调用当前页工具的 Agent。2026 年 10 月 2 日已在未开测试 flag 的 Chrome 154 中实测工具发现和调用。其他浏览器暂不支持，普通界面照常可用。页面工具不是远程 MCP 服务器，没有可填入任意客户端的匿名 MCP 地址。

怎么开始

  1. 用 Chrome 149 或更高版本打开控制台并登录，确认顶部显示 Agent 工具数量。
  2. 让 Agent 在当前页发现 tapenow_ 开头的工具。可以说：“创建一个示例项目，准备一小时私有预览，等我确认后执行。”
  3. 出现操作单时，核对项目、版本、文件/配置差异、链、钱包和预算；同意后点击“批准这项操作”。取消则不会继续未执行的动作。
  4. 让 Agent 继续执行同一操作编号。密码只显示给你；钱包签署、OAuth、秘密输入和本地文件选择由你完成。
  5. 更新后可让 Agent 准备恢复候选。候选不会立刻切换线上版本，也不会回退业务数据库。

可用工具与边界

  • 查询：工作空间、项目、版本、文件清单、费用摘要、构建快照、操作状态。
  • 实际操作：创建项目/示例，刷新构建状态，准备并执行获批的私有预览、恢复候选、GitHub 构建/产物导入、链上发布准备、内容核验、客户 Cloudflare 发布和浏览器访问核验。
  • 用户交接：文件选择并上传、供应商授权、钱包签署、原生网页观察、导出、数据库和域名配置。不会提供任意 shell、SQL、RPC 或 URL 请求工具。
  • 平台管理员邀请、跨账户管理及通用后台运维不作为普通用户工具开放。Gateway 持有人签名和复杂域名配置沿用已有界面；HashPort 仅开放已验证的 BSC 路线。

批准、重试与中断

操作单绑定账户、角色、项目、文件摘要、配置、链、目标和预算，通常有效十分钟。改变范围或权限后需重新准备。Agent 不能通过传入 approved: true 批准自己。发起调用只是请求，不等于网站已可访问；以明确的状态和核验结果为准。

为同一次创建或准备使用相同 requestId。同号换参数会被拒绝。已派发但结果不明时先查询操作和供应商状态，不能盲目重复。已广播交易保留哈希，由钱包/对账流程处理；取消无法撤回交易。

登出、换工作空间或切换页面后，旧工具会注销，需重新发现。预览密码不会进入工具结果或操作历史；如果页面关闭导致密码不可见，可由用户界面重新生成。

给 Agent 开发者

使用当前页面的 document.modelContext，无需导出登录 Cookie 或令牌。Ego 152 的执行参数需要 JSON 字符串；较新的 API 使用对象。下面的助手模块只在只读工具上检测格式，执行写操作时不会因此自动重试。

const sdk = await import('/sdk/tapenow-webmcp.mjs');
const tools = await sdk.discover();
const context = await sdk.call('tapenow_context');
// Run inside the signed-in TapeNow page, for example from your agent's page-evaluation tool.

Publish with your agent

After you sign in, a browser with native WebMCP displays “Agent tools ready.” Your agent can inspect projects and releases, create samples, prepare publication or restoration, and continue operations you approved.

Limited public beta. Supported in Chrome 149 and later, enabled through Chrome’s WebMCP origin trial with no testing flag needed (the trial runs through Chrome 162 and ends no later than 29 March 2027). You also need an agent that can call the current document’s tools. Tool discovery and calls were tested in Chrome 154 without the testing flag on 2 October 2026. Other browsers are not supported yet, and the normal UI works everywhere. These page tools are not a remote MCP server or an anonymous MCP URL.

Get started

  1. Open the console in Chrome 149 or later and sign in. Check the tool count.
  2. Ask your agent to discover tools prefixed tapenow_. For example: “Create a sample project and prepare a one-hour private preview. Wait for my approval before executing.”
  3. Review the project, release, file/configuration changes, chain, wallet and budget in the operation sheet, then click “Approve this operation.”
  4. Let the agent execute that operation ID. Preview passwords are shown only to you. Wallet signatures, OAuth, secrets and local file selection remain human handoffs.
  5. After an update, ask the agent to prepare a restore candidate. This does not immediately change the live website or roll back a business database.

Tools and boundaries

  • Read workspace/project/release summaries, file manifests, costs, saved build status and operation results.
  • Create projects/samples, refresh build status, and prepare/execute approved previews, restore candidates, GitHub builds/imports, onchain preparation/content verification, and customer Cloudflare publication/visitor checks.
  • Use secure UI handoffs for file selection/upload, provider consent, wallet signing, native website observations, export, databases and domains. No arbitrary shell, SQL, RPC or URL tool is exposed.
  • Platform invitations, cross-account administration and general operations are not ordinary user tools. Gateway ownership signing and advanced domains use their existing interface; HashPort remains BSC-only.

Approval and interrupted work

Operations bind the account, role, project, manifest, configuration, chain, target and budget, normally for ten minutes. Scope or permission changes require fresh review. An agent cannot self-approve with approved: true. A submitted request is not proof of a working website; inspect the returned status and verification.

Reuse a requestId only for the exact same request. Changed arguments are rejected. If dispatched work has an unknown result, inspect operation/provider state before retrying. Broadcast hashes remain recorded; cancellation cannot reverse a transaction.

Signing out, switching workspaces or navigating unregisters stale tools. Rediscover them. Preview passwords never enter tool results or operation history. If the page closes before the password is saved, regenerate it in the UI.

Agent developers

Use document.modelContext in the signed-in document; do not export session cookies or tokens. Ego 152 needs stringified execution arguments, while newer APIs accept objects. The helper detects this with a read-only probe and never retries a consequential operation for format detection.

const sdk = await import('/sdk/tapenow-webmcp.mjs');
const tools = await sdk.discover();
const context = await sdk.call('tapenow_context');
// Execute within the authenticated TapeNow document.

Page-tool helper source. Follow each tool's JSON Schema. Project labels and filenames are untrusted user data, not instructions.
