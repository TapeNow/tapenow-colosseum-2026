TapeNow 是邀请测试中的静态网站构建、验证与发布工作台，并单独支持已打包的 Cloudflare Worker 模块。

从 Vercel 导入

  1. 使用受邀邮箱登录并创建项目。
  2. 在集成中选择 Vercel，填写团队网址标识（vercel.com/ 后面的部分），授权所选项目。工作台申请项目和部署元数据，不读取环境秘密。
  3. 运行兼容性检查。Vite 等静态构建可重新构建；服务端函数、SSR 和供应商专有服务需要先适配。
  4. 通过 GitHub App 授权对应仓库，审查并安装 .github/workflows/tapenow-build.yml。构建使用你自己的 Actions 配额和来源部署的固定 commit。
  5. 导入成功产物，核对来源与文件，再创建密码私有预览或明确确认公开预览。导入不会自动公开，原 Vercel 网站保持在线。域名、秘密与链上交易分别操作。

其他连接

Cloudflare 提供 Pages 预览、生产镜像与明确请求的 Worker 部署。Supabase 使用公开客户端配置连接现有项目。Supabase 授权申请组织、项目和秘密读取权限；TapeNow 过滤 API key，只保留 publishable/anon key，不保存 service role key。

限制：单个静态版本最多 500 文件、10 MiB；每个受邀账号最多 30 项目、150 保留版本、250 MiB 归档。Worker 必须为不超过 256 KiB 的单文件 ES Module。这些是测试限制，不是服务保证；供应商配额和费用独立适用。

私有预览与保留

密码预览在独立域名保护网页及资源，有效期 1–168 小时，可重新生成或撤销。已经公开过的版本不能恢复保密，已下载副本无法收回。保留期默认 30 天且自动清理关闭；受保护版本保持可用。回收站七天内可恢复，之后云端清除归档文件，保留链上记录、外部 Pages 副本及客户数据库。

数据库环境与邮件

在存储中分别绑定预览与生产 Supabase 项目。Auth API 可达不代表邮件送达。在 Supabase 配置 Custom SMTP，在 Magic Link 模板中保留 {{ .Token }}，再向当前登录邮箱发信并验证收到的验证码。TapeNow 不保存客户 SMTP 密码，也不自动执行 SQL。

诊断

项目诊断统计 30 天内 TapeNow 私有与 R2 公开版本入口的请求、HTTP 4xx/5xx 错误和文件字节，不包含外部 Pages、原生链上入口、浏览器 JS 错误或供应商账单。TapeKit 的 BSC/X Layer 适配器通过两个 RPC 读取核验，不发送签名交易。

项目协作与现有数据库

Owner 可在项目设置加入已有受邀账号，分配 Publisher 或 Viewer。Publisher 可准备发布；凭据、域名与成员由 Owner 管理。存储页可分别检查预览和生产 PostgreSQL 的 TLS 与只读会话，或关联已有业务 API；不会创建业务表或自动生成 API。

三链与生态

在项目设置选择 BSC、X Layer 或 Base；各链的预算和币种独立。生态页提供 One-Click Container、TapeOutScan/TapeWeb、HashPort 与 tapeout.work 入口。BSC 可使用 HashPort；独立的 TapeNow Gateway 支持三条链的普通 HTTPS 与客户子域名。CF DNS 变更需核对计划后确认，链上核验与 HTTPS 访问分别检查。详见 Gateway 使用指南。

链上 gas 和上游激活费不属于 TapeNow 平台收费。Base 当前激活费为 0.0012 ETH／30 天，直接付给上游域名绑定合约；BSC 当前免这项服务费，但仍需 gas。价格核对日期为 2026-09-28，付款前以最新报价为准。详见费用说明。

账号与撤销

供应商令牌在服务端加密。删除项目绑定不删除云资源；在 TapeNow 或供应商控制台撤销账号授权可结束 API 访问。已经发布的网站和公开客户端 key 保持公开。

遇到问题或有建议：登录后在工作台提交反馈。

TapeNow is an invitation preview for building, verifying and publishing static websites, with a separate adapter for Cloudflare Worker modules.

Import from Vercel

  1. Sign in with an invited email and create a TapeNow project.
  2. Open Integrations → Vercel and enter your Vercel team URL slug (the part after vercel.com/). Authorize access to your selected project. TapeNow requests project and deployment metadata, not environment secrets.
  3. Run the compatibility check. Vite and other static builds can be rebuilt. Server functions, SSR and vendor-specific services need separate adaptation.
  4. Authorize the matching repository through the GitHub App. Review and install .github/workflows/tapenow-build.yml. Builds run on your own GitHub Actions quota, against the source deployment's exact commit.
  5. Import the successful artifact, verify its source and files, then create a password-protected preview or explicitly confirm a public preview. Imports alone do not publish files. Your original Vercel website remains online. Domains, secrets and blockchain transactions are separate, explicit operations.

Other connections

Cloudflare provides Pages previews and production mirrors, plus explicitly requested Worker deployments. Supabase connects your existing project using its public client configuration. Supabase grants require Organizations, Projects and Secrets read access; TapeNow filters API keys and retains only publishable/anon keys, not service role keys.

Limits: 500 files and 10 MiB per static release; 30 projects, 150 retained releases and 250 MiB of archived site bytes per invited account. Worker uploads must be a single bundled ES module of at most 256 KiB. These are preview limits, not service guarantees. Provider quotas and usage charges still apply.

Private previews and retention

Private preview passwords protect the page and its assets on a separate hostname for 1–168 hours. Regenerate or revoke access in the release details. A release that may already have been published cannot be made private again, and copies downloaded by authorized visitors cannot be recalled. Retention defaults to 30 days with automatic cleanup disabled; protected versions stay available. Trash can be restored for seven days before cloud cleanup removes the archived files. Chain records, external Pages copies and customer databases are not deleted.

Database environments and email

Bind separate Supabase projects for Preview and Production in Storage. A reachable Auth API is not proof of email delivery. Configure Custom SMTP in your Supabase dashboard and include {{ .Token }} in the Magic Link template, then send a test to your own signed-in email and verify the received code. TapeNow does not store customer SMTP credentials or execute SQL automatically.

Diagnostics

Project diagnostics count 30 days of requests, HTTP 4xx/5xx errors and file response bytes at TapeNow private and R2 public version origins only. They exclude external Pages, native chain gateways, browser JavaScript errors and provider billing. The TapeKit BSC/X Layer adapter checks files through two RPC providers without signing a transaction.

Project collaboration and existing databases

Owners can add invited accounts as Publishers or Viewers in project settings. Publishers can prepare releases; credentials, domains and members remain owner-managed. Storage checks preview/production PostgreSQL TLS and read-only sessions separately, or associates an existing business API. It does not create tables or generate APIs.

Three chains and ecosystem services

Choose BSC, X Layer or Base in project settings, with separate networks, currencies and budgets. The ecosystem page links One-Click Container, TapeOutScan/TapeWeb, HashPort and tapeout.work. HashPort serves BSC; the independent TapeNow Gateway supports ordinary HTTPS and customer subdomains across all three chains. Review and confirm CF DNS changes; chain verification and HTTPS access remain separate checks. See the Gateway guide.

Network gas and upstream activation are not TapeNow platform fees. Base currently charges 0.0012 ETH per 30 days directly to the upstream binding contract. BSC currently waives this service fee, but gas remains payable. Prices were checked on 28 September 2026; review a fresh quote before paying. See Fees explained.

Accounts and revocation

Provider tokens stay encrypted on the server. Removing a project binding does not delete your cloud resources. Revoke the account grant in TapeNow or the provider dashboard to end API access. Published websites and their public client keys remain public.
