# TapeNow · 参赛精选审阅副本

准备日期：**2026-10-08**，审阅包 **修订 2**。版本 **0.9.16**，源快照 `07eefe8828e3215ea53694feff854c1ac9c66c4d`，产品审阅基线 `4fb1603124bdba4a0edc53a63f555e559390af55`。本副本等待所有者确认后才可对外分享；包含真实 React 工作台、Express 服务和测试，**不是仅有工具的 SDK，也不是完整线上服务或可直接部署生产的项目**，未改变原有权利或开源许可。

运行需要 Node.js 22.12+ 与 npm。安装需要访问包仓库；本地演示不需要生产凭据、真实邮箱、钱包、Docker 或 Cloudflare 账号：

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run check
npm run build
npm test
npm run test:demo
npm start
```

打开 `http://127.0.0.1:4311`，本地模式无需云端登录，使用原有 loopback、Host、Origin 和会话防护。不要将它暴露到互联网。首次运行自动建立本地 `.data/` 状态及本地签名/加密材料，本导出不包含这些文件；测试也会建立临时密钥与合成钱包。可用 `DEWEB_DATA_DIR` 选择其他本地目录，默认端口为 4311/4312。演练不配置供应商凭据。

可以复现：示例 v1/v2 或静态构建导入、文件清单、loopback 预览、旧版恢复候选、ZIP 导出及签名/哈希验证；演示测试同时验证篡改会被拒绝。恢复候选不会自动公开，恢复网页不回滚数据库。

包含云端密码预览真实模块及内存 fixture 测试，但本地 UI 不提供该面板。未包含线上 Worker 入口、部署配置、迁移或运维；不能复现真实登录、邮件、人机验证浏览器流程、OAuth、公开托管、链上交易或完整生产服务。相关 UI/模块保留用于理解，不代表已配置。公有链合约地址与上游引用保留用于核对。

TapeOut 提供协议/合约、DeWeb 容器及芯片权限，TapeKit 提供原生检索。TapeNow 提供易用的导入、预览、版本管理、发布检查、编排、恢复和导出工作流。Gateway 是常规云快照；链上多笔更新不是原子切换。归档验签只证明所下载文件与可信签名一致，不能证明当前线上字节；公钥指纹必须通过独立可信渠道固定，线上验证还需独立检索全部目标文件并比对 manifest。
